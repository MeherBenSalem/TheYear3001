# Chronofall 2.1.0 — Stabilizer

A player asked for a way to keep rifts away from their base. 2.1 adds a block that does exactly that.

Available for Minecraft 1.20.1 (Fabric, Forge), 1.21.1, 26.1.2, 26.2 and 26.3 (Fabric, NeoForge), with the same
features and ids everywhere. Install on the server and on clients. Worlds from 2.0 load unchanged.

## New
- **Rift Stabilizer** (`chronofall:rift_stabilizer`): a natural Chrono Rift never lands within 32 blocks
  (horizontal distance) of a Rift Stabilizer. When the spot a rift picks is too close, it picks another one, up to 8
  times; if every spot is covered, no rift opens that time and the player's rift timer restarts as usual. A
  stabilizer only counts while its chunk is loaded (it never loads chunks).
  Fabricator recipe: 4 Rift Glass, 4 Titanium Ingots, 1 Processor, 2 Rift Shards (12 seconds). Mine it with an iron
  pickaxe or better; it gives off a soft light (level 7).
- **Config** `rifts.stabilizer_radius` (default `32`, 0 to 128; `0` turns stabilizers off). Existing config files get
  the new key on the next start.

## Changed
- Rift Beacons and `/chronofall rift_at <pos>` ignore stabilizers: they are rifts you ask for. `/chronofall rift
  [player]` behaves like a natural rift and says so when stabilizers cover every spot it tried.
- The Fabricator has 21 recipes.

## Compatibility
- Minecraft 1.20.1: Fabric (Fabric API 0.92.2+), Forge 47.4.0+
- Minecraft 1.21.1: Fabric (Fabric API 0.116.0+), NeoForge 21.1.219+
- Minecraft 26.1.2: Fabric (Fabric API 0.145.4+), NeoForge 26.1.2.7-beta+
- Minecraft 26.2: Fabric (Fabric API 0.152.1+), NeoForge 26.2.0.93+
- Minecraft 26.3: Fabric (Fabric API 0.165.0+), NeoForge 26.3.0.97+
- Java 17 (1.20.1), 21 (1.21.1), 25 (26.x). No other dependencies.
